# Exposure algorithm contract (V2)

The standalone exposure-algorithm plan is the normative source; the implementation MUST not substitute full-frame-average rolling means. Filename order defines the timeline: capture time and camera file numbering are never inputs.

1. Analysis is from fixed-WB, fixed-rendered **linear** RGB. No per-frame exposure auto-scaling. Analyze after linear area downsampling (long edge <= 1024), ROI in display coordinates, 12×8 tiles or reduced grid with >=256 samples per tile.
2. Pixel luminance is 0.2126R+0.7152G+0.0722B. For each tile, use 5%/5% trimmed **linear** mean, then log2. Reject nonfinite values, mean <= max(1e-5,8*quantum), or saturation occupancy > 0.005.
3. Remove only the user-confirmed step vector before fitting. Detect scene cuts between consecutive frames on the step-adjusted tile values: with >=max(8,ceil(K/4)) tiles valid in both frames, a cut requires |median tile delta| >= 0.20 EV AND scaled cross-tile MAD >= 0.08 EV. A spatially uniform jump is common flicker, never a cut. Within each content-continuous segment, fit every valid tile using Huber-data / second-difference Whittaker smoothing with 64-bit banded IRLS, 100 iterations max, 1e-5 EV threshold, delta=0.1 EV, lambda=1/(16 sin(pi/P)^4), P_eff=min(P,segment length).
4. Take residual median across tiles; require >=max(8,ceil(K/4)) valid tiles, >=60% within 0.06 EV, scaled MAD<=0.06 EV and consensus tiles from at least 3 of 4 ROI quadrants.
5. Interpolate only internal gaps of <=3 frames between trusted residuals inside one segment; never span entire corrections, scene cuts or edge gaps. Report unreliable values as null / REVIEW_REQUIRED, not silent zero.
6. Raw correction = strength * (-confirmed_step - residual); each segment anchors to the median of its own reliable raw corrections, so exposure continuity is never claimed across a scene cut. Segments shorter than 8 frames are SHORT_SEQUENCE_NO_DEFLICKER (confirmed steps still apply). Preserve separate requested_ev, applied_ev and render_ev, and explicit clipping with status LIMITED. Scene cuts and per-frame segment ids are reported, not silent.
7. Disabled strength=0 produces zero EV. Whole sequences shorter than 8 frames are no-automatic-deflicker but confirmed steps may still apply. Do not auto-derive steps from EXIF. brightness=uniform instead targets one constant output level: the per-frame common level (median of step-adjusted valid tiles, same minimum tile count) is corrected to the global median level with the same strength scaling, EV clipping, LIMITED reporting and review semantics; scene cuts are report metadata only, and real trends are deliberately flattened.
8. Freeze tile targets from original analysis; verify renderer at -0.25/+0.25 EV on up to five representative RAW frames; track observed error and retry at most twice, never regenerate targets or mix prior encoded frames. Bad probe/validation is reported, not misrepresented as success.
9. No per-frame highlight-protection gain adjustments. Exposure gain is applied to linear sensor/render data before sRGB OETF. 16-bit clipped output and surrogate saturation masks are explicitly approximate.
10. The expected mathematical tests cover constant and linear trends, 25% contaminated tiles, step semantics, gap crossing, saturation, severe low light, numerical nonfinite and memory bounds, the true-global-flash ambiguity, and scene-cut segmentation (splice splits, uniform jumps stay unsplit, short middle segments pass through, confirmed steps never cut).

The algorithm's outputs are **not** proof of correct natural-scene change classification; users choose the time-scale and optionally an ROI. Scene-cut thresholds are calibrated constants, not a claim that every real-world splice is distinguishable from flicker; a statistically indistinguishable splice is absorbed by the trend instead of cutting.

## V3 (2026-11-05) — flicker-fix cycle

The contract gained the following invariants from the real-output flicker work (F0-F9):

1. **Acceptance is independent.** Gain probes and render checks verify execution consistency only. Publication is gated (unless <code>--temporal-quality report/off</code>) by an independent decoded-video temporal audit; <code>OK</code> never implies "no flicker" by itself. The four benchmark ROIs never participate in fitting.
2. **Estimation is matched-background.** The default estimator is a sparse pair graph (lags 1/2/4/8/16, structure/colour/saturation gates, Huber IRLS, one gauge per component, evidence-free frames stay unknown). Per-frame medians of whatever occupies the frame are not exposure evidence. The legacy path stays selectable for comparison, never mixed into metrics.
3. **Targets have provenance.** Frames carry <code>measured_level_ev</code> and <code>desired_level_ev</code>; targets are frozen before render iterations; feedback adjusts execution, never intent. Uniform references the persistent background (global assumption or per-segment); smooth preserves confirmed steps and the slow trend; neither applies a low-pass to the final correction.
4. **Continuity is evidence, not assumption.** Capture-time gaps (ExifTool, optional), filename suspicions, structural cuts and confirmed steps are reported as distinct kinds; statistics never cross confirmed gaps.
5. **DNG semantics are probed, not guessed.** <code>rawtl probe-dng</code> verifies per machine whether BaselineExposure and OpcodeList3 are actually executed; run reports record owner/support status and per-opcode payload variation. Adobe-reference development stays <code>not_tested</code> where unavailable.
6. **Colour is declared.** sRGB-OETF pixels, explicit BT.709 matrix, limited range, transfer tag <code>iec61966-2-1</code>; missing encoder tags raise contract warnings, never silence.

Schema version is now **2** (finite JSON only). Reports written by version 1 remain readable as historical artifacts; their <code>OK</code> must be re-audited with <code>rawtl audit-video</code> before being quoted as flicker-free.
